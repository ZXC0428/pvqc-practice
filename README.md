# PVQC 商業與管理詞彙模擬測驗

可直接在瀏覽器離線使用的 PVQC 商業與管理類詞彙練習工具，題庫共收錄 1,514 筆詞彙。

## 開始使用

直接以瀏覽器開啟 `index.html` 即可，不需要安裝套件或啟動伺服器。

## 設定測驗

1. 輸入題庫的起始與結束編號，例如 `1` 到 `100`；也可只選單一題。此範圍只限制每題的正確答案；另外三個干擾選項會從完整題庫隨機抽取。
2. 輸入每個測驗要出的題數。預設為所選範圍的完整題數，也可自行改成較少的題數，例如範圍 `1–20`、出 `10` 題。
3. 選擇回饋模式。
   - **練習模式**：作答後立即顯示正確答案與原詞彙庫編號。
   - **模擬測驗模式**：作答後只顯示答對或答錯，不顯示答案；完成題組與全部測驗後，可查看錯題題號、原詞彙庫編號與自己的作答，但不顯示正確答案。
4. 勾選要進行的測驗類型，可複選。

每一個勾選的測驗都會分開進行：各自隨機出題、各自計時 10 分鐘、各自統計成績；不會把不同測驗類型混成同一個題組。

## 測驗類型

- 測驗 2：看英文，選中文
- 測驗 3：聽英文發音，選中文
- 測驗 4：聽英文發音，選正確拼字（正解搭配近似拼錯選項）
- 測驗 5：看中文，聽選英文發音
- 測驗 6：看英文，聽選英文發音

## 聽力操作

- 測驗 3、4：按「播放題目發音」可重複聽題目。
- 測驗 5、6：進入題目時會依序播放四個選項一次；每個選項都可個別重播，不限次數，再按該選項的「選擇此答案」作答。
- 英文發音使用瀏覽器的英語文字轉語音，速度為正常值；常見縮寫會套用較自然的朗讀規則，例如 `B/L` 會讀為 `bill of lading`。這不是 PVQC 官方錄音。
- 選擇答案後，系統會立刻停止目前正在播放的題目或選項發音。

## 作答規則與快捷鍵

- 每題均為四選一，選項顯示詞性。
- 答題送出後即鎖定，不能回上一題修改。
- `1`、`2`、`3`、`4`：選擇對應選項。
- `Enter`：在已作答後前往下一題；最後一題則完成題組。
- 作答畫面會顯示目前的回饋模式、剩餘時間、題組答對／答錯數與目前題號。
- 完成全部勾選的測驗後，總結頁會列出各題組的正確數、錯誤數、正確率及錯題原詞彙庫編號。

## 專案結構

```text
pvqc-practice/
├─ index.html                 # 網頁進入點
├─ README.md                  # 使用說明
├─ css/
│  ├─ style.css               # 基礎樣式與版面
│  ├─ selection.css           # 首頁設定區
│  ├─ theme.css               # 色彩與元件主題
│  ├─ range.css               # 題庫範圍欄位
│  ├─ wide.css                # 大螢幕與 RWD 版面
│  ├─ feedback.css            # 作答回饋樣式
│  ├─ audio-choice.css        # 聽力選項樣式
│  └─ mode-badge.css          # 回饋模式標示
├─ js/
│  ├─ vocabulary.js           # 題庫資料
│  ├─ app.js                  # 測驗流程與畫面邏輯
│  └─ keyboard.js             # 鍵盤快捷鍵
└─ tools/
   └─ build-vocabulary.mjs    # 題庫轉換工具
```

## 更新題庫

若要重新從來源資料產生題庫，請在專案根目錄執行：

```powershell
node tools/build-vocabulary.mjs
```

此指令會更新 `js/vocabulary.js`。
