# PVQC 商業與管理詞彙模擬測驗

這是一個可離線開啟的單頁網頁測驗工具，使用 PVQC 商業與管理詞彙庫製作四選一練習題。

## 開始使用

直接以瀏覽器開啟 `index.html` 即可使用，不需要安裝套件、伺服器或網路連線。

## 設定測驗

1. 輸入題庫起始與結束編號，例如 `1` 到 `100`。
2. 輸入每個測驗要出的題數；預設會帶入該範圍的完整題數。
3. 勾選要進行的測驗題型。
4. 按下「開始測驗」。

每個勾選的測驗會獨立進行：有自己的題目、10 分鐘倒數、成績與錯題複習。完成一個測驗後，再按「開始下一個」進入下一項。

## 題型

- 測驗 2：看英文，選中文
- 測驗 3：聽英文發音，選中文
- 測驗 4：聽英文發音，選英文
- 測驗 5：看中文，聽選英文發音
- 測驗 6：看英文，聽選英文發音

發音使用瀏覽器內建的英文語音朗讀功能。

## 作答規則與快捷鍵

- 每題只有一次作答機會；選答後會立即顯示答對或答錯、原詞彙庫編號與正確答案。
- 作答後不能返回或修改前題答案。
- 按鍵 `1`、`2`、`3`、`4` 可選擇 A、B、C、D。
- 作答完成後按 `Enter` 可前往下一題；最後一題按 `Enter` 可交卷。
- 每一題完成後都會顯示目前測驗的累積答對與答錯數量。
- 全部勾選的測驗完成後，最終頁會提供各題組與全部合計的答對、答錯及正確率。

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁結構與所有畫面元素 |
| `js/app.js` | 題目產生、計時、作答、成績與總結流程 |
| `js/keyboard.js` | `1` 至 `4` 與 `Enter` 的鍵盤操作 |
| `js/vocabulary.js` | 1,514 筆詞彙題庫資料 |
| `css/style.css` | 原始基礎樣式 |
| `css/selection.css` | 題型選擇、統計與結果區樣式 |
| `css/theme.css` | 響應式版面與視覺主題 |
| `css/range.css` | 題目範圍與題數輸入欄位樣式 |
| `css/wide.css` | 寬螢幕版面調整 |
| `tools/build-vocabulary.mjs` | 從原始 Word 詞彙表重新產生題庫的工具 |

## 題庫更新

若更新了原始 Word 詞彙表，可在此資料夾執行：

```powershell
node tools/build-vocabulary.mjs
```

此工具會重新建立 `js/vocabulary.js`。
